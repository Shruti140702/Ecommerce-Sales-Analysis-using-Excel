An E-commerce Sales Analysis Dashboard in Excel provides a detailed overview of sales performance and profitability, including:  

1. **Key Metrics**: Total sales, profit, quantity sold, and number of orders.  
2. **Category Insights**: Sales, profit, and profit margin by product categories and subcategories.  
3. **Geographic Performance**: Sales and profitability analysis by state to identify top-performing regions.  
4. **Profitability Trends**: Overall and segment-wise profit margins to highlight areas for improvement.  
5. **Order Trends**: Number of orders over time to analyze peak demand periods.  

The dashboard leverages pivot tables, charts, and conditional formatting to provide clear, interactive insights for strategic decision-making.
